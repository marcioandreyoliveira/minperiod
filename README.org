* How to execute the program
** Retrieve the historical prices
#+begin_src bash
  python ./getprices <ticker> <period> <days>
#+end_src

Valid arguments
<ticker>: A valid ticker on B3 (example: TAEE3)
<period>: 1, 5 or 10 (value in minuters)
<days>: 1 to 60.
*NOTE*: If <period> = 1, then maximum returned days = 7.

Example:
#+begin_src bash
  python ./getprices TAEE3 5 60
#+end_src

** Analize
#+begin_src bash
python analise_minimas.py <ticker> <path to CSV files> <days>
#+end_src

Exemple
#+begin_src bash
  # assuming that CSV files are at the same directory level than analise_minimas.py
  python analise_minimas.py TAEE3 . 60
#+end_src

*NOTES*: Only files whose filename start with the ticker will be used in the analysis.
